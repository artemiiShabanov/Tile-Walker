# Tile-Walker

Гиперказуалка для смартфонов про шагание по плитке: реалистичная физика скелета на джоинтах, управление в один тап

Godot 4.4. Проект Godot лежит в `tile-walker/`: открыть `tile-walker/project.godot` в редакторе, запуск F5.

- План и прогресс: [docs/PLAN.md](docs/PLAN.md), [issues](https://github.com/artemiiShabanov/Tile-Walker/issues)
- Дизайн: [docs/GDD.md](docs/GDD.md), решения в [docs/DESIGN.md](docs/DESIGN.md), спеки в [docs/specs/](docs/specs/)
- Процесс работы: [gamedev-hub/WORKFLOW.md](https://github.com/artemiiShabanov/gamedev-hub/blob/main/WORKFLOW.md)
